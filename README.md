# 코드 한 문제 · 정처기 실기

C·Java·Python 문제를 유형별로 풀고 즉시 정답과 해설을 확인하는 정적 웹앱입니다.

- 총 360문항: 언어별 120문항
- 기존 자체 제작 대표 문제 72개 + 새 코드 유형 72개 × 데이터 변형 4개
- 출력 직접 입력, 객관식 출력 선택, 변수·참조 추적, 빈칸·오류 수정
- 언어·유형·형식·난이도·학습 상태 필터
- 핵심 72문항, 유형별 순차 풀이, 유형이 겹치지 않도록 우선 선택하는 무작위 20문항
- 즉시 채점, 짧은 해설, 중간 상태 표, 모범 수정 코드
- 오답·해설 확인 문제 복습, 즐겨찾기, 오답 메모
- 진도와 세션 복원, 선택적 20분 타이머, 글자 크기·다크 모드
- 오프라인 사용과 홈 화면 설치
- JSON 백업 내보내기·가져오기: 기기 간 수동 이동

## 사용

GitHub Pages 주소를 Chrome 또는 Safari에서 엽니다. 첫 접속에서는 온라인 상태로 앱과 문제를 저장하며, ‘오프라인 풀이 준비 완료’를 확인한 뒤 오프라인으로 다시 사용할 수 있습니다.

- Android: Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가
- iPad/iPhone: Safari 공유 → 홈 화면에 추가 → 웹 앱으로 열기(표시될 때)

각 기기의 기록은 별개입니다. 설정의 백업 파일로 기록을 옮길 수 있으며 자동 동기화는 하지 않습니다. 브라우저 데이터를 지우기 전 백업하세요.

## 문제와 채점

모든 문제는 자체 제작이며 실제 기출 원문이 아닙니다. 360문항의 실행 가능한 풀이를 Python·C11·Java17 환경에서 실제 실행해 예상 결과와 대조했습니다. 빈칸·오류 수정형은 모범 수정안을 실행했습니다. C 문자 코드는 ASCII를 가정합니다.

출력은 마지막 줄바꿈과 줄 끝 공백을 무시하고, 중간 공백·대소문자는 구분합니다. 식·키워드 답안은 공백과 끝 세미콜론을 무시합니다. 입력한 코드를 서버로 보내거나 실행하지 않고, 브라우저에서 미리 검증한 정답과 비교합니다.

## 배포·개발

빌드나 별도 서버가 필요하지 않습니다. 이 폴더의 파일을 저장소 루트에 놓고, GitHub Settings → Pages에서 main 브랜치의 /(root)를 선택합니다. 상대 경로만 사용하므로 프로젝트 하위 주소에서도 동작합니다. 서비스워커는 HTTPS 또는 localhost에서만 동작합니다.

파일을 바꿀 때는 `sw.js`의 CACHE 버전을 함께 올려 오프라인 캐시를 갱신하세요. 앱의 사용자 기록은 GitHub에 전송되지 않습니다.

GitHub 웹 편집기용 배포본은 CSS·앱·문제를 index.html에 포함하고 PNG 아이콘을 데이터 URL로 포함합니다. 기능과 문제는 분리형 배포본과 같습니다.
